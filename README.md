# Turbohub ETL (fin-analyzer)

Браузерный ETL для финансовых выгрузок: загрузка Excel/CSV/Google Sheets, 8 правил трансформации, выгрузка результата.

Полное ТЗ, список ошибок исходного прототипа и исправления — в [TZ.md](./TZ.md).

## Запуск

```bash
npm install
npm test
npm run dev
```

Сборка: `npm run build`.
